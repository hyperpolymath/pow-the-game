= POW: The Game — Roadmap
:toc: auto

== Phase 0: Research & Platform Survey ← _current_

Goal: understand what is actually possible on each platform before
committing to any architecture.

* [ ] Steamworks SDK capability survey via `steamworks-rs`
** Workshop item read/write from Rust
** P2P networking primitives (Steam Datagram Relay)
** Lobby/matchmaking as coordination bus
* [ ] Garry's Mod GLua sandbox analysis
** What compute is safe to run client-side?
** Can Workshop mods receive dynamic payloads?
** Latency/throughput of Lua ↔ game ↔ server round trip
* [ ] Factorio circuit network feasibility
** Model a SAT fragment as a circuit; measure clock speed
** Benchmark: gates per second on typical hardware
* [ ] Roblox Luau sandboxing limits
** DataStore API as shared state?
** Script execution time limits

== Phase 1: Minimal Proof of Concept

Goal: prove one problem class distributable across one platform.

* [ ] Choose problem class (candidate: random graph 3-colouring search)
* [ ] Write fragmenter in Rust
* [ ] Write minimal Garry's Mod worker (GLua)
* [ ] Write verifier in Idris2 (formally proven correct)
* [ ] Integrate via steamworks-rs lobby
* [ ] Measure: throughput, latency, correctness rate

== Phase 2: Aggregation Layer

* [ ] Gleam-based fault-tolerant aggregator (BEAM supervisor tree)
* [ ] Result deduplication + quorum verification
* [ ] Reconnect/rejoin handling (players leave mid-computation)
* [ ] Persistence layer (VeriSimDB instance)

== Phase 3: Second Platform

* [ ] Port worker to Factorio or Roblox
* [ ] Measure cross-platform result consistency

== Phase 4: Incentive Model Research

* [ ] Survey opt-in mechanisms (not silent background compute)
* [ ] In-game reward designs (leaderboard, cosmetics, acknowledgement)
* [ ] Ethics review: player consent, compute cost, disclosure

== Phase 5: Publication / Open Design

* [ ] Write up findings as design document / informal paper
* [ ] Decide what to open-source (verifier? fragmenter? platform bridges?)
* [ ] Keep worker implementations private if platform TOS requires it
